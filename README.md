# 優待券チェッカー(COUPON THRESHOLD CHECKER)

一定額ごとに使える優待券を効率的に活用するための、お買い物計算ツールです。

## 概要

2,000 円ごとに 1,000 円の優待券が使える条件で、1,900 円の商品を買うのはちょっともったいない。そんな「あと何円で大活躍できる状態になるか」をリアルタイムに可視化します。

商品の単価と数量を入力すると、設定した閾値（デフォルト 2,000 円）を基準に、**合計金額**・**今すぐ使える優待券の数**・**次の1枚まであと何円か**をリアルタイムに表示します。

## 使い方

1. ヘッダーの「円ごとに1枚」で、1枚の優待券と交換できる金額を設定（デフォルト 2,000 円）
2. 「＋ 商品を追加」で商品名・数量・単価を入力
3. 合計金額・優待券数・次の1枚までの残り金額（プログレスバー付き）がリアルタイムに更新される

入力内容は `localStorage` に自動保存され、ページを閉じても維持されます。

## 主な機能

- リアルタイム計算・ダークモード対応・レスポンシブデザイン
- 単ファイル配布：`couponcalc.html` 1つで完結。ブラウザで開くだけ
